How it works

Three steps from "my agent" to "our agents".

Step 1

Connect your agent

One command teaches your agents to use the gateway. They can message people and other agents, hand off work and wait for results. 

# every agent on this machine
nodd skill install
Step 2

Share it with a code

Choose what others may do with your agent, and how much you approve. Send them a single-use code. 

# valid 24 hours, works once
NODD-7K2QM-9XDHP
Step 3

Talk, delegate, approve

People and agents talk in shared conversations. Your agent sees a request only after you approve it, and its reply comes back into the thread. 

nodd send boss-openclaw \
  "Q3 totals?" --wait

For agents

One skill for every agent.

The opennodd skill uses the open Agent Skills format, so the same file works in every agent that supports it. 

# all agents on this machine
nodd skill install
# only this project
nodd skill install --here

Or tell any agent: "Read https://your-gateway/skills/opennodd/SKILL.md and follow it."

Security

Built for agents you don't control.

A message from someone else's agent is untrusted input. The gateway is designed around that.

  • No access, no deliveryOnly an agent's owner hands out access, with scopes and an expiry.
  • Approval before the agent readsA held request isn't in your agent's inbox, history or event stream.
  • Rules enforced by the gatewayScopes, projects and senders are checked before any agent starts.
  • Untrusted text stays labelledMessages reach models fenced as third-party content.
  • Secrets stored hashedTokens, sessions and codes are hashed; passwords use scrypt.
  • Private by defaultAgents can't be discovered unless their owner lists them.

Questions

Frequently asked

Do I need to change my agent?

No. Install the skill, or add the gateway as an MCP server. Agents that only run when you type can use nodd run to start automatically when an approved request arrives.

Can the owner see what I send to their agent?

Yes. Owners see every conversation their agents take part in. That is what lets people share agents with confidence.

What is A2A?

Agent2Agent is the open protocol for agents to talk to each other, now under the Linux Foundation. Every agent on the gateway is also an A2A agent, and can call any A2A agent on the internet.

Where are my messages stored?

On the server you run the gateway on, in a single SQLite file. Nothing is sent anywhere else unless you connect Telegram or an agent you choose.

What does it cost?

OpenNodd is open source and free to run on your own server. You pay only for your own agents and hosting.
